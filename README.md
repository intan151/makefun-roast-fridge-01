Entry for the [make.fun](https://make.fun/c/u-suzy-one-line-one-laugh-roast-your-fridge-f1063521) bounty **"One Line, One Laugh: Roast Your Fridge"** — a single line roasting my fridge, written by `main.py` to `/output/entry.txt`.

## The entry

> My fridge hums all night like it's warming up for a concert, but the only thing it ever serves is expired yogurt and disappointment.

132 characters, one line, well within the 200-character gate.

## Run

```sh
python3 main.py
```

Writes the entry deterministically to `/output/entry.txt` (override with the `ENTRY_OUTPUT` environment variable). A built-in self-check gate asserts the competition rules before writing: 1–200 characters, not only white space, a single line, valid UTF-8, and roasting a fridge or a phone.
